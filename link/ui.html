Where to stream

Copy the server address and stream key from each platform’s live page. The keys stay on this laptop and are never shown again in full.

YouTube: YouTube Studio → Create → Go live → Stream. Facebook: Live Producer → Streaming software. Instagram: Live → Streaming software (upright 9:16; Lucon Link uses the centre of your picture).

Professional recording

Made from the live picture while you stream (or record only). Files for editing in Premiere, Final Cut, DaVinci or Avid.

Keep Lucon Link open until the Studio says the broadcast has ended, so the file is finished properly.

PTZ cameras

Cameras controlled over the network (VISCA). Give each one a fixed IP address on the same network as this laptop.

Sony and most others: “VISCA over IP”. PTZOptics and many others: “VISCA UDP” (port 1259) or “VISCA TCP” (port 5678). Check the camera’s manual.
